# API integration sources

Verified 2026-11-06 from official documentation:

- Open-Meteo: free/open-access tier, no key required, non-commercial use, 10,000 calls/day, 600/min, 5,000/hour, no uptime guarantee. https://open-meteo.com/en/pricing
- Frankfurter: free/open-source exchange-rate API, no key required, 239 currencies, no monthly/daily quota; abuse rate-limited. https://frankfurter.dev/
- JokeAPI: no key required; 120 requests/minute per client; safe-mode and blacklist flags available. https://sv443.net/jokeapi/v2/
- TheMealDB: free API; development test key 1; public app-store releases may require supporter access. https://www.themealdb.com/api.php
- CoinGecko: free Demo plan, 10,000 call credits/month and 100 calls/minute. https://www.coingecko.com/en/api/pricing
- LibreTranslate: open-source and self-hostable; hosted service may require an API key. https://docs.libretranslate.com/
- NewsAPI: Developer plan is free for development/testing, 100 requests/day, 24-hour article delay, not for production use. https://newsapi.org/pricing
- REST Countries: current docs describe a free 1,000-request monthly plan and API-key authentication; the plugin also tries the legacy public v3.1 endpoint. https://restcountries.com/docs
- Nominatim: public endpoint requires an identifying User-Agent, attribution, caching, and maximum one request/second; no autocomplete or bulk use. https://operations.osmfoundation.org/policies/nominatim/
- Gemini Developer API: free tier exists for selected models with free input/output tokens; limits/model availability vary and free-tier content may be used to improve products. https://aistudio.google.com/docs/pricing
